# Credit-Card-ML-project

 About the Project
This project predicts whether a credit card customer will default on their payment next month using Machine Learning.

It uses customer details, credit limits, payment history, and bill amounts to make predictions.

 Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

 Dataset
- 30,000 customer records
- 25 columns
- Target variable: Default Payment Next Month
  - 0 – No Default
  - 1 – Default

 Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

 Steps Performed
1. Data Loading
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Data Visualization
6. Outlier Detection
7. Feature Selection
8. Train-Test Split
9. Model Training
10. Model Evaluation

 Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 78% |
| Decision Tree | 71% |
| Random Forest | 81% |

 Conclusion
The Random Forest Classifier performed better than the other models with an accuracy of 81%.

This project demonstrates how Machine Learning can help predict credit card payment defaults and support better financial risk management.
